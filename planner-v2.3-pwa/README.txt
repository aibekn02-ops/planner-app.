Планировщик 2.3 — PWA для Android

1. Разместите содержимое папки на HTTPS-хостинге (например, GitHub Pages или Netlify).
2. Откройте HTTPS-ссылку в Chrome на Android.
3. В меню Chrome выберите «Установить приложение» или «Добавить на главный экран».
4. После первого успешного открытия онлайн приложение сможет открываться офлайн.

Важно: http://192.168.x.x не поддерживает Service Worker/PWA-установку как HTTPS. Локальный http://localhost на ноутбуке подходит для тестирования, но не на телефоне.
Данные сохраняются только в локальном хранилище конкретного браузера/адреса и НЕ синхронизируются. Перенос данных из версии 2.2 пока не реализован. Не удаляйте предыдущую версию и её данные. Уведомления и синхронизация ещё не реализованы.
